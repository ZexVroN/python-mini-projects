\# Python Calculator



A simple command-line calculator built with Python as my first mini project.



\## Features



The calculator currently supports:



\* Addition (`+`)

\* Subtraction (`-`)

\* Multiplication (`\*`)

\* Division (`/`)

\* Division-by-zero validation

\* Invalid operator validation



\## Example



```text

Input : First number = 10

Input : Second number = 5

Input : Operator = \*



10 \* 5 = 50

```



Division by zero:



```text

Input : First number = 10

Input : Second number = 0

Input : Operator = /



10 tidak bisa dibagi dengan 0

```

\* Variables

\* Arithmetic operators

\* `if / elif / else`

\* Logical conditions

\## What I Learned



The most important lesson from this project was learning how programming concepts work together to solve a real problem.



I initially created a basic calculator, then discovered a `ZeroDivisionError` when attempting to divide by zero. After fixing that problem, I discovered another logic issue when an unsupported operator was entered.



This led me to improve the program using conditional branching and nested conditions.



The project is intentionally simple and will be improved as I learn more Python concepts.
