\# Contact Manager V1



Mini project Python untuk mengelola data kontak menggunakan List dan Dictionary.



Project ini dibuat sebagai latihan penerapan Data Structures Python, khususnya List dan Dictionary.



\## Features



\- Add Contact

\- Show Contact

\- Search Contact by Index

\- Search Contact by Name

\- Delete Contact by Index

\- Delete Contact by Name

\- Exit Program
