\# Number Guessing Game



A simple command-line number guessing game built with Python.



The computer generates a random number, and the player keeps guessing until they find the correct number.



\## Features



\* Generates a random number

\* Accepts user guesses

\* Tells the player when the guess is too high

\* Tells the player when the guess is too low

\* Continues asking for guesses until the correct number is found



\## Example



```text

Number = 1

Tebakan salah nilai terlalu kecil



Number = 3

Tebakan salah, nilai terlalu besar



Number = 2

Tebakan benar, nomor = 2

```
